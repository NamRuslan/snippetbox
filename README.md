# Snippetbox - Веб сервис заметок на идиоматичном Go

Пет-проект, реализованный в рамках погружения в экосистему Go (на базе книги Алекса Эдвардса *«Let’s Go»*).

**Цель проекта для меня (Ведущий Java разработчик):** освоить идиоматичный подход Go, работу со стандартной библиотекой без тяжелых фреймворков (аналогов Spring), управление зависимостями через явный DI, а также стандартные паттерны тестирования и безопасности в Go.

---

## Архитектура и ключевые решения

Проект построен по классической слоистой архитектуре с четким разделением ответственности:
* **Transport / HTTP layer (`cmd/web`):** маршрутизация, middleware цепочки, обработка ошибок, управление сессиями и рендеринг.
* **Domain (`internal/models`):** бизнес-сущности и слой доступа к данным (Repository pattern) без использования ORM.
* **Dependency Injection:** явная передача зависимостей через структуру `application` без магии рефлексии и DI контейнеров.

---

## Технологический стек и примененные пакеты

В проекте сделан упор на стандартную библиотеку Go:

* **Язык:** Go 1.26;
* **Веб и Middleware:**
    * `net/http` - базовая работа с HTTP-сервером, настройка таймаутов (`ReadTimeout`, `WriteTimeout`, `IdleTimeout`) и TLS (HTTPS).
    * `justinas/alice` - композиция цепочек middleware (логирование запросов, восстановление после паник, установка security-заголовков, аутентификация).
* **База данных:**
    * `database/sql` + `pgx` - работа c PostgreSQL БД и ее синтаксисом;
* **Безопасность и сессии:**
    * `alexedwards/scs/v2` - управление серверными сессиями с хранением состояния в БД.
    * `justinas/nosurf` - защита от CSRF атак.
    * `golang.org/x/crypto/bcrypt` - хеширование и верификация паролей.
* **Логирование и конфигурация:**
    * `log/slog` - структурированное логирование из стандартной библиотеки.
    * `flag` - парсинг параметров запуска через CLI-флаги.
* **Тестирование:**
    * `testing` + `net/http/httptest` - модульные и интеграционные e2e тесты HTTP хендлеров и middleware (использование subtests и table driven подхода).
